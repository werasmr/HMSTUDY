# Обновления на Render

Render подключён к GitHub. Когда код попадает в ветку `main`, Render **автоматически пересобирает** backend и frontend.

## Как обновить сайт

1. Изменения в коде → commit → push в `main`
2. Render Dashboard → увидишь новый деплой (5–10 мин)
3. Готово — сайт обновлён

## Миграции базы

При деплое backend автоматически запускает:
```
npx prisma migrate deploy
```

Новые таблицы (например Wallet) создадутся сами.

## Если что-то сломалось

Render → сервис → **Logs** → смотри ошибку.

## Безопасность (что добавлено)

- Регистрация только как **TRADER**, без выбора роли ADMIN
- ADMIN/MERCHANT создаёт только администратор
- JWT проверяется в базе, заблокированные пользователи не входят
- Деньги: атомарные транзакции, защита от двойного списания/разморозки
- Кошельки USDT назначает **только админ**
- Баланс пополняет **только админ** (DEPOSIT/WITHDRAWAL)
- Споры и чат — только участники сделки

## Админ-панель

Войти как `admin@prismapay.com` / `password123`:

- **Пользователи** — создать трейдера/мерчанта, пополнить баланс, заблокировать
- **Кошельки** — назначить USDT-адрес трейдеру
